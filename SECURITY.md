# Security Policy

## Supported Versions

Only the latest release is supported.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

[Report vulnerabilities privately](https://github.com/samueldervishii/hydra/security/advisories/new). Include:

- Steps to reproduce
- Affected versions
- Potential impact

This project is maintained on a best-efforts basis. There are no guaranteed response times for security reports.
